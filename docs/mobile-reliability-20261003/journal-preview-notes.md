# Journal mobile previews

Rendered actual Flutter widgets at 390 × 844 logical pixels using the app theme, bundled Inter and icon fonts. These are controlled UI fixtures, not production records.

- refill-history.png: monthly receipt spending and observed usage shown separately, with saved entry.
- refill-form.png: full-screen phone refill entry.
- cylinder-change-form.png: explicit change type, optional cylinder capacity/empty-weight snapshot; scrolls to notes and Save entry.
- bottle-scan-history.png: searchable reported scan readings, verified/failed filters and date range. Repeated device reports may repeat a code.
- alert-team-activity.png: assignment, handover note, resolution with note and server-attributed audit entry.

All five previews were visually inspected. No overflow or missing glyphs. The temporary capture test was removed after rendering.
