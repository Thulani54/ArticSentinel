# Sentinel workspace redesign

The interface is a monitoring workspace for cold-chain and gas operators. Equipment, connection state and actionability take precedence over promotional content.

Palette: polar #F2F6F9, white #FFFFFF, deep sea #133648, signal blue #176BBA, frost #DDEDF5 and gas copper #BF521B. Green, amber and red remain semantic status colours.

Typography: Manrope for navigation and data; Archivo for headings and the wordmark. Left-aligned text, tabular measurements and restrained sentence-case labels.

Layout: persistent 248px equipment navigation | workspace header and flexible content. On small screens navigation becomes a modal drawer. The dashboard places a fleet connection strip above searchable equipment cards; secondary pages share the same tables, panels, forms, controls and status language. Sign-in uses a large cold-storage illustration beside the form.

Review: a generic dark dashboard and decorative charts would obscure the actual equipment. Use a light workspace, a compact fleet availability bar driven by device records, and an architectural cold-room illustration only on sign-in. No fictional live measurements or health claims.

All existing API contracts and operational actions are retained. Gas simulation remains visibly identified wherever shown. Build output and dependencies are excluded from Git.
